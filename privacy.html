Privacy Policy

Last updated: November 19, 2026

Purpose

This application is a personal rclone integration used to synchronize files between my private GitHub repository and my Google Drive.

Google User Data

The application requests Google Drive access to list, read, upload, update, and manage files. The authorized scope also permits file deletion.

Data Usage and Storage

Google Drive data is accessed only to perform personal file management and synchronization. Authentication credentials are stored locally or, when automated synchronization is enabled, in GitHub Actions encrypted secrets.

Data Sharing

Google user data is not sold or used for advertising. Data is processed by Google Drive and GitHub Actions as necessary for the synchronization workflow.

Access Revocation

Google Drive access can be revoked at any time through Google Account security settings.
